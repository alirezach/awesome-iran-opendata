# Awesome Iran open data

![Open Source](https://img.shields.io/badge/Open_Source-مجوز_آزاد-007EC6?style=flat&logo=open-source-initiative&logoColor=white)   ![Open Data](https://img.shields.io/badge/Open_Data-داده‌_باز-008000?style=flat&logo=open-access&logoColor=white)      ![GitHub Repo stars](https://img.shields.io/github/stars/alirezach/awesome-iran-opendata)

Este repositorio se creó con la idea de facilitar el acceso y familiarizar a investigadores y periodistas con datos abiertos centrados específicamente en Irán, e incluye fuentes gubernamentales, centros de investigación oficiales, organismos internacionales e instituciones independientes de intercambio de datos<br>
(¡Apóyanos poniendo una estrella y compartiendo este proyecto con quienes sean investigadores o periodistas!)
